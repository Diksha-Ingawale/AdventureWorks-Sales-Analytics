# AdventureWorks Sales Analytics

## Project Overview
This project analyses AdventureWorks sales data using Python, Pandas, NumPy, Matplotlib, Seaborn, and Power BI. The objective is to explore sales performance, identify business trends, and present meaningful insights through visualizations and an interactive dashboard.

## Objectives
- Prepare and clean the sales dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyse product, category, and regional sales performance.
- Create visualizations to identify business patterns.
- Develop an interactive Power BI dashboard.
- Provide data-driven business recommendations.

## Dataset
The project uses the AdventureWorks Sales Excel workbook, which contains sales, product, customer, reseller, date, and territory information.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Power BI
- Git and GitHub

- Product sales performance.
- Yearly sales trends.
- Regional sales performance.
- Sales amount distribution.

## Dashboard
The interactive Power BI dashboard presents sales KPIs, product and category performance, regional analysis, and sales trends. It includes interactive filters for exploring the data.

## Conclusion
This project demonstrates the use of data analytics tools to prepare, analyse, visualize, and interpret business sales data. The findings can support better sales monitoring and business decision-making.
